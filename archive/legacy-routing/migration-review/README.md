# Former migration review screens

These are the source snapshots from before consolidation into the shared Imports
workspace. They are reference backups outside all application build contexts.
Their historical relative imports are not executable from this directory.

Runtime `/admin/migrations` links redirect to `/admin/import` and package review;
the redirect preserves item/source selection and pagination. The active shared
implementation is documented in `docs/design/import-review-workspace.md`.
